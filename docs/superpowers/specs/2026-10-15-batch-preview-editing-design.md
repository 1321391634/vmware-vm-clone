# 批次预览逐台编辑设计

## 目标

将批次预览从只读汇总表改为表格内直接编辑。每一行代表一台待创建的虚拟机，并且每一行的最终配置都必须传递到 vCenter 克隆请求。范围包括：

- 虚拟机名称、Hostname、IPv4；
- 目标存储、端口组；
- CPU、内存；
- 新增硬盘列表。

同时修复静态 IPv4 自动补全的边界问题，并让新增硬盘默认为空。

## 已确认的交互方案

采用 A 方案：表格内直接编辑。

### 表格编辑器

预览表格保留每台任务一行，列为：

`序号 / 名称 / Hostname / IP / 计算资源 / 存储 / 端口组 / CPU / 内存 / 新增硬盘 / 电源`

编辑方式：

- 名称、Hostname、IP 使用单元格文本编辑器；
- 存储和端口组使用可搜索下拉框；
- CPU、内存使用数字编辑器；
- 新增硬盘单元格显示当前磁盘摘要，点击后打开紧凑磁盘编辑器，可添加多块磁盘、设置容量和 GB/TB、删除磁盘；
- 计算资源和电源策略仍由批次级参数控制，本轮不做逐行修改；
- 表格保留横向滚动，完整值通过列宽和 Tooltip 可读。

表格刷新时不重建用户已经编辑的行状态。行草稿以序号为键保存，只有参数校验成功后才替换当前有效计划。

## IPv4 设计

静态 IPv4 表单改为两个字段：

- `IPv4 分配初始地址`：可编辑，例如 `192.168.1.191`；
- `IPv4 分配结束地址`：根据克隆数量自动计算，默认只读，例如数量为 3 时显示 `192.168.1.193`。

计算使用 `ipaddress.IPv4Address` 的整数运算，不使用字符串最后一段替换，因此 `191` 会正确计算为 `191、192、193`。如果计算会超过 `255.255.255.255`，结束地址显示错误状态，计划校验阻止执行。

批次预览中的每行 IP 仍然可以直接修改。逐行修改后，以逐行 IP 为最终值，并校验地址格式、重复和已上报冲突。子网掩码、网关、DNS 仍保持批次级配置。

## 数据流与模型

`CloneItem` 增加每台任务的有效配置：

- `datastore_name`；
- `portgroup_name`，`None` 表示继承源网卡；
- `cpu_count`；
- `memory_gb`；
- `disk_requests`。

计划构建分两步：

1. `build_clone_plan` 根据批次表单生成默认的 `CloneItem`，名称、Hostname、IP、存储、端口组、CPU、内存和空磁盘列表全部展开到每一行。
2. UI 将表格编辑结果应用到这些行，并调用领域层校验函数，校验所有名称、Hostname、IP、存储、端口组、CPU、内存和磁盘值后生成新的不可变 `ClonePlan`。

`ClonePlan` 的批次级字段继续保留，用于文件夹、计算资源、自定义规范、网络公共参数、电源策略、备注和报告兼容；执行时以 `CloneItem` 的逐台字段为准。

## vCenter 执行边界

`VmwareCloneGateway.clone_one(plan, item)` 改为：

- 使用 `item.datastore_name` 定位 datastore；
- 使用 `item.portgroup_name` 构造网卡，`None` 时保留并规范化源网卡；
- 使用 `item.cpu_count` 和 `item.memory_gb` 填充 ConfigSpec；
- 使用 `item.disk_requests` 添加磁盘；
- 使用 `item.vm_name`、`item.hostname`、`item.ip_address` 进行命名和客户机自定义。

这样并发执行和失败项重试仍然复用现有执行器，但每一项重试时使用的是该行最后一次校验通过的配置。

## 新增硬盘默认行为

初始化时不创建任何磁盘行。点击“添加硬盘”才创建第一行。删除最后一块后立即触发：

- 行状态更新；
- 当前计划重新构建；
- 批次预览同步显示“无新增”。

空磁盘列表会传递为不生成 `deviceChange` 磁盘操作，不影响源虚拟机已有磁盘。

## 校验与错误处理

- 行内名称和 Hostname 使用现有规则；
- CPU 和内存必须为正数；
- 存储必须存在于当前 inventory；
- 端口组必须是“继承源网卡”或当前 inventory 中的对象；
- 静态 IP 必须是合法 IPv4，批次内不能重复；
- 新增磁盘容量必须大于 0，单位只允许 GB/TB；
- 所有行校验失败时，预览状态显示具体行号和字段，不允许开始克隆；
- 重新生成默认计划时，只保留仍然存在的行编辑值，数量减少时丢弃超出的行，数量增加时新增默认行。

## 测试范围

领域测试覆盖：

- `192.168.1.191` 数量 3 生成结束地址 `192.168.1.193`；
- 跨 `255` 边界和 IPv4 溢出；
- 逐行不同名称、Hostname、IP、存储、端口组、CPU、内存和磁盘；
- 行内重复名称/IP和非法资源；
- 空磁盘计划不产生磁盘变更。

UI 测试覆盖：

- IPv4 初始/结束字段联动；
- 默认硬盘列表为空；
- 删除最后一块硬盘后预览立即更新；
- 存储/端口组单元格使用可搜索编辑器；
- 编辑一行后刷新预览不会丢失其他行的修改。

网关测试覆盖：

- 每台任务使用自己的 datastore、端口组、CPU、内存和硬盘；
- 继承端口组和显式端口组行为不回归。
