# vm-clone 控制室改造设计

## 目标

将现有 vm-clone 改造成明亮、稳重、适中密度的桌面运维工作台，并降低单文件 Windows EXE 的体积，同时保持现有批量克隆功能和单文件交付方式。

## 视觉方向

采用已确认的 B 方案“明亮控制室”：暖白工作区、深墨色文字、蓝色主操作、青绿色成功状态和低对比暖灰边界。布局保留左侧资源、右侧向导和实时预览，但将顶部、步骤、资源表、结果区设计成统一的工作台层级，减少重复卡片和冷灰边框。

## 依赖瘦身

- 移除 `openpyxl`，使用标准库 `zipfile` 和 XML 生成包含批次参数与克隆结果的 XLSX。
- 移除 `keyring`，使用 Windows DPAPI (`CryptProtectData`/`CryptUnprotectData`) 加密密码，密文单独写入用户数据目录，配置元数据不存明文密码。
- 在打包 spec 中排除未使用的 Qt 模块、`numpy`、`lxml`、PIL、测试模块和多余凭据后端。
- 报告导出和 VMware 连接模块在动作发生时再加载，启动路径只加载 Qt、领域模型和本地配置。

## UI 结构

- 顶部连接栏：品牌、配置选择、vCenter 地址/账号、连接状态和操作按钮分组。
- 左侧资源区：连接统计、搜索/筛选工具条、虚拟机表格、选中对象摘要。
- 右侧工作区：步骤导航、当前步骤标题、分组表单、继承值提示和明确的错误/成功状态。
- 底部预览区：数量、并发、目标资源、名称/IP 结果表和校验/执行状态。
- 所有资源选择继续使用可搜索控件；按钮、表头、空状态、加载状态和禁用状态使用统一样式。

## 数据流和兼容性

现有 `CloneForm`、`ClonePlan`、`PreflightValidator`、`CloneExecutor` 和 VMware 网关接口保持不变。UI 只负责收集参数与展示结果；报告、凭据和打包实现替换为轻量边界。用户数据仍写入 `%LOCALAPPDATA%\\vm-clone`。

## 验收

- 完整测试通过。
- 新 XLSX 能被标准 ZIP/XML 结构检查打开，包含“批次参数”和“克隆结果”两个工作表。
- Windows DPAPI 凭据可保存、读取、删除，profiles 元数据不含明文密码。
- PyInstaller onefile 构建成功，启动检查通过，体积较原约 76.6 MB 明显下降。
- Qt offscreen 截图检查主要窗口和空状态，不出现控件重叠或异常空白。
